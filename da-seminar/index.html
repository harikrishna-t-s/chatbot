Quick Review

The Foundation

Before we model complex data, we must remember the rules of the game.

Axioms

Probability always ranges from 0 to 1.

Bayes

Updating beliefs based on new evidence—the core of AI.

Events

Distinguishing between Independent and Dependent outcomes.

Transition: In basic probability, we look at single events. In Data Analytics, we look at "Random Variables"—mapping these events to numbers so we can build models.

Advanced Probability

Bayes' Theorem & Conditional Probability

How do we update our beliefs when we encounter new evidence? This is the foundation of modern Machine Learning.

P(A|B) = [P(B|A) * P(A)] / P(B)

Real-World Application: Spam Filters

If an email contains the word "Lottery" (Event B), what is the probability that the email is Spam (Event A)? Bayes' theorem calculates this by looking at how often the word "Lottery" appears in known spam emails.

Medical Testing Paradox

Even if a disease test is 99% accurate, if the disease is extremely rare (low prior probability P(A)), a positive result might still mean you most likely don't have the disease. Bayes reveals these unintuitive truths.

Real-World Examples

Spam Filtering

Given an email contains 'Lottery', calculate the updated probability it is spam based on past data.

Medical Testing

Updating the probability a patient actually has a disease after receiving a positive test result.

Weather Forecasting

Adjusting the baseline chance of rain today based on the new evidence of dark clouds forming.

Part 01: Mapping Reality

Introduction to Random Variables

What is it?

A Random Variable (X) is a mathematical function that maps the outcomes of a random process to real numbers.

Why do analysts care?

Computers can't "calculate" on events like "Customer Churned" or "Rainy Day." We map these to 1 or 0 so we can perform regression, clustering, and forecasting.

Analogy: The Uber Ride

The "Event" is a ride from Point A to B. The "Random Variable" could be the Wait Time, the Fare, or the Driver Rating.

Categorization

Discrete vs. Continuous

Discrete Variables

Countable values. No "in-between" exists.

  • Number of Netflix subscribers.
  • App crashes per day.
  • Inventory stock count.

Continuous Variables

Measurable values. Infinite precision.

  • Server response time (ms).
  • Employee salary.
  • Temperature in a data center.
Concept Check

Is the "Price of Bitcoin" a discrete or continuous variable?

Real-World Examples

E-commerce Platforms

Discrete: Number of items in a shopping cart. Continuous: The total checkout price.

Server Infrastructure

Discrete: Number of concurrent users logged in. Continuous: Server CPU Temperature.

Healthcare Tech

Discrete: Daily steps tracked by a smartwatch. Continuous: Blood pressure readings.

The Heart of Data

Probability Distributions

A distribution tells us how the values of a random variable are spread out. It answers: "Which outcomes are most likely?"

Normal

The Bell Curve

Human heights, IQ, and error rates.

Binomial

Success/Failure

A/B testing: Click vs. No Click.

Poisson

Events in Time

Orders arriving at Zomato per hour.

More Key Distributions

Uniform

The "Fair" Distribution

Every outcome has an equal chance. Example: Rolling a fair 6-sided die, or generating a random number between 0 and 1.

Exponential

Time Between Events

Models the time elapsed between events in a Poisson process. Example: How long until the next server failure, or the next customer arrival.

Live Visualization: Normal Distribution

In Data Analytics, the Standard Deviation (σ) determines the width of the curve, representing volatility.

Real-World Examples

Normal

Analyzing standardized test scores (like SAT/GRE) or heights of a population.

Binomial

Measuring Click-Through Rates (CTR) where a user either clicks (Success) or doesn't (Failure).

Poisson

Predicting the number of customer support tickets a call center will receive in the next hour.

Part 02: Decision Science

Hypothesis Testing

How analysts turn "hunches" into scientific facts.

The Problem

A Marketing Manager claims a new "Dark Mode" UI increases user session time. Is this luck or real effect?

The Solution

We use Hypothesis Testing to calculate the probability that the result happened by chance.

P-Value

The "Evidence Score." If P < 0.05, the result is statistically significant.

Significance Level (α)

The threshold for risk. Usually set at 5% (0.05).

Type I Error (False Positive)

Rejecting the Null Hypothesis when it is actually true (e.g., Convicting an innocent person).

Type II Error (False Negative)

Failing to reject the Null Hypothesis when it is actually false (e.g., Letting a guilty person go free).

Real-World Examples

Marketing Conversion

Testing if a new ad campaign significantly increases the conversion rate compared to the old one.

Clinical Trials

Determining if a new vaccine reduces infection rates significantly compared to a placebo.

UX Design

Checking if a new navigation bar reduces the average time-to-checkout for users.

The Legal Framework of Statistics

Null (H₀) vs. Alternative (H₁)

Hypothesis Status Quo Real-World Example (Amazon)
Null (H₀) "Nothing changed." The new checkout button does not improve sales.
Alternative (H₁) "There is an effect." The new checkout button increases sales.

Analyst Tip: We never "prove" the Alternative. We only find enough evidence to "Reject the Null."

Continuous Inference

Z-Test vs. T-Test

Before jumping to categorical data (Chi-Square), how do we compare averages?

T-Test (Most Common)

Used when comparing the means of two groups, especially when the sample size is small (n < 30) or the population standard deviation is unknown.

  • Is the average salary of Data Scientists different from Data Engineers?
  • Does a new drug lower blood pressure more than a placebo?

Z-Test

Used for comparing means when the sample size is large (n > 30) AND the population standard deviation is known.

  • Quality control in manufacturing where historical population variance is established.

Real-World Examples

Z-Test: Manufacturing

Checking the average weight of millions of produced screws (population variance is known).

T-Test: Education

Testing the average test scores of 20 students taught with a new experimental method.

2-Sample T-Test

Comparing the average salaries between two small engineering teams to check for parity.

The Categorical Engine

The Chi-Square (χ²) Test

Used to see if there is a significant relationship between two Categorical variables.

χ² = Σ [ (Observed - Expected)² / Expected ]

Case Study: Smartphone Preference

Step 1: Expected Values

Calculate Expected = (Row Total × Column Total) / Grand Total.

Step 2: Compute Score

Apply the formula for each cell, square the difference, and divide by the Expected value.

Chi-Square helps us determine if "Age Group" and "Phone Choice" are Independent or linked.

Real-World Examples

Demographics

Is there a relationship between Age Group (Gen Z/Boomers) and Preferred Social Media (TikTok/Facebook)?

E-commerce

Does the Device Type (Mobile/Desktop) affect the Payment Method chosen (Credit Card/PayPal)?

Education

Is a student's Major (CS/Art) independent of their Preferred Study Environment (Library/Cafe)?

The Estimation Layer

Confidence Intervals

Instead of a single point estimate, we often want a range of values that likely contains the true population parameter.

95% Confidence

If we sampled the population 100 times, 95 of those intervals would contain the true mean.

Margin of Error

Determines the width of the interval. A larger sample size reduces the margin of error.

Industry Standard

A/B Testing: The Netflix Approach

A/B testing is the randomized experimentation process where two or more versions of a variable (web page, page element, etc.) are shown to different segments of users.

1. Hypothesis

Define the Null and Alternative. e.g., H₁: Changing the CTA color to Red increases Click-Through-Rate (CTR).

2. Experiment

Randomly route 50% of traffic to Control (Blue) and 50% to Variant (Red). Collect metric logs.

3. Analysis

Run a 2-proportion Z-test or Chi-Square to determine if the CTR difference is statistically significant.

Guardrail Metrics: Always track secondary metrics. Your new red button might increase clicks, but it could also increase the uninstallation rate!

Real-World Examples

Pricing Page Layout

Testing whether defaulting to the 'Annual Plan' toggle increases total revenue compared to 'Monthly'.

Email Marketing

Sending 'Sale Ends Soon' to 50% of users and '20% Off Everything' to the other 50% to maximize open rates.

Recommendation Engine

Routing traffic between Algorithm A and B to see which yields higher average watch-time on Netflix.

Practical Application

Interactive Lab: Python Implementation

Run these calculations in your own environment to see how it works in practice.

import scipy.stats as stats
import numpy as np

# Observed Data (Gen Z vs Boomers on Phone Choice)
observed = np.array([[85, 15], [40, 60]])

# Perform Chi-Square Test
chi2, p_val, dof, expected = stats.chi2_contingency(observed)

print(f"Chi-Square Score: {chi2:.2f}")
print(f"P-Value: {p_val:.5f}")

Interview Questions

Population is the entire group (e.g., all Google users). Sample is a subset (e.g., 1000 users we surveyed) used to make inferences about the population.

Use Chi-Square for categorical data (e.g., Gender, Color, Yes/No). Use T-test for comparing means of continuous data (e.g., Height, Salary).

The CLT states that if you take large enough samples from a population and calculate their averages, those averages will form a Normal Distribution (a bell curve)—regardless of what the original population's distribution looked like. It’s why the bell curve is everywhere in statistics.

Statistical power is the probability of correctly rejecting a false Null Hypothesis (i.e., successfully detecting a real effect). A larger sample size increases your power because it gives you a clearer, more confident view of the data, minimizing the chance of a Type II Error.
